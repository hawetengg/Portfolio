# Portfolio

Static site: index.html, styles.css, script.js. No build step.

## Run
Open the folder in VS Code, install the Live Server extension, right-click index.html > Open with Live Server.

## Before you publish
1. In index.html, replace YOUR_FORM_ID in the form action with your Formspree form id
   (create a form at formspree.io with the email you want messages sent to).
